# Bestcomp — сайт магазина (bestcomp.kg)

Сайт компьютерного магазина Bestcomp, Бишкек. Публикуется через GitHub Pages на домене **bestcomp.kg** (файл `CNAME`).

Данные (каталог, готовые сборки, фото) сайт только читает из Firebase-проекта `sklad-rbit`;
их выгружает программа «Склад и касса» (репозиторий KruzhnovSergei/sklad).

Сайт раньше жил в папке `site/` репозитория sklad — теперь источник здесь, правки вносить в этот репозиторий.
