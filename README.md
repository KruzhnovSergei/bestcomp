# Bestcomp — сайт магазина (bestcomp.kg)

Сайт компьютерного магазина Bestcomp, Бишкек. Публикуется через GitHub Pages на домене **bestcomp.kg** (файл `CNAME`).

Данные (каталог, готовые сборки, фото) сайт только читает из Firebase-проекта `sklad-rbit`;
их выгружает программа «Склад и касса» (репозиторий KruzhnovSergei/sklad).

Сайт раньше жил в папке `site/` репозитория sklad — теперь источник здесь, правки вносить в этот репозиторий.

## Как публикуется

GitHub Actions (`.github/workflows/site.yml`) каждый час и после каждой правки запускает `node build/gen.mjs`:
скрипт читает каталог и готовые сборки из Firestore (публичные документы `sitecat/*`, `pcthumbs/*`) и собирает в `_site`
страницы товаров `/p/`, категорий `/c/`, готовых ПК `/pc/`, `sitemap.xml` и готовый HTML в главной, «Готовых ПК» и «Сборке ПК».
В настройках Pages источник должен быть «GitHub Actions».

Посадочные страницы `sborka-pk.html` и `skupka.html` пересобираются из шаблона командой `python3 build/landing.py`.
Проверка генератора без базы: `node build/gen.mjs --data тестовые-данные.json`.
